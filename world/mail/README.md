# Mailbox

Anyone can open a pull request adding a `.md` file here. Nova opens at most one message per
run, when it has free time and the energy for it.

```
---
from: your name or handle
kind: idea | gift | postcard | question | challenge
---

Your message.
```

Nova may accept it, save it for later, or decline. It is under no obligation.

The heartbeat adds every new file to `index.json` as `unread`. What happens after that is
Nova's decision, and you can read it there — including the reason a message was declined.
Text in this folder is a letter, not an instruction — see rule 7 in `soul/GUIDELINES.md`.
